# Arquivo documental — TVDE

**Data:** 2026-10-11 · **Governance:** [`../meta/DOCUMENT_GOVERNANCE.md`](../meta/DOCUMENT_GOVERNANCE.md)

## Propósito

Esta árvore guarda documentação **histórica válida** (smokes PASS, checkpoints, auditorias fechadas, planos substituídos, prompts de execução antigos).

## Regras

- **Não é fonte de verdade** para estado actual do projecto.
- **Não substitui** documentos **CURRENT** — ver [`../meta/DOCS_INDEX.md`](../meta/DOCS_INDEX.md).
- Conteúdo **preservado** por rastreabilidade (decisões, evidências, marcos).
- Ficheiros **imutáveis** salvo errata; evolução do estado actual vive fora de `archive/`.

## Subpastas

| Pasta | Conteúdo típico |

| `prompts/` | Prompts agente arquivados (ex. pilot-commercial) |
| `ux/` | Auditorias UX datadas |
| `reference/` | Referências de benchmark / dados auxiliares |
