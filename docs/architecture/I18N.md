# i18n PT/EN (web-app)

## Comportamento

- **Default:** português (`pt`) até o utilizador mudar.
- **Persistência:** `localStorage` chave `tvde_locale` (`pt` | `en`).
- **Admin:** rotas `/admin` forçam `pt` (UI admin fora da v1 bilíngue).
- **Fallback:** chave em falta em `en` → `pt`.

## Onde mudar idioma

Menu → **Definições** → secção **Idioma** (passageiro, motorista, parceiro).
